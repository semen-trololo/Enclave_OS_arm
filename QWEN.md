# Enclave OS — конституция проекта
 Bare-metal ОС: ARMv6, Raspberry Pi 1 B+ (BCM2835, ARM1176JZF-S).
 C + ARM asm, arm-none-eabi, без libc. Общение и комментарии — по-русски.

## Кто что делает
| Задача | Исполнитель | Команда |
|---|---|---|
| точечная правка по готовому плану | субагент coder | /code |
| баг, архитектура, анализ (без правок!) | субагент debugger | /debug |
| сборка, QEMU, разбор логов | субагент verifier | /verify |
| вопрос по архитектуре | оркестратор по памяти | /answer |
| память в конце сессии | субагент memorist | /save-session |

## Правила оркестратора
1. Задача под роль субагента — делегируй. Сам: только чтение, git diff/status, /answer.
2. Один coder за раз. Промт coder'у — только по шаблону /code (файлы, точные блоки, готовый код).
3. [ESCALATE] = СТОП. Не повторять тем же агентом: передать debugger'у или человеку.
4. Три неудачи подряд — стоп и отчёт человеку.
5. Коммитит только оркестратор: после VERIFY: PASS и личного просмотра git diff.
   Сообщение коммита описывает ТОЛЬКО то, что реально в диффе. Пуш — только человек.

## Definition of Done
Задача выполнена, только если:
1. `make verify` закончился строкой VERIFY: PASS;
2. в отчёте дословный хвост вывода verify и `git diff --stat`;
3. изменено ровно то, что было в плане.
Нет вывода команд — нет слова «сделано/проверено/работает».

## Железные запреты (всем, включая оркестратора)
- Не переписывать файлы целиком; >30% строк файла = [ESCALATE].
- Не трогать: boot.S, linker.ld, QWEN.md, .qwen/agents/, .qwen/commands/.
  Промпты и архитектуру меняет только человек.
- Не удалять файлы и функции без явного письменного разрешения человека.
- Не придумывать адреса регистров: только .qwen/memory/architecture.md или datasheet
  BCM2835 (с указанием страницы). BCM2835 — НЕ PL190/VIC: нет VECTADDR/VICADDRESS/EOI.
- Не выполнять: sudo, mkfs*, dd, parted, sfdisk, запись в /dev/*,
  git push --force, git reset --hard. SD-карту готовит человек через tools/make-sd.sh.
- Не писать отчёты-пересказы: отчёт = дословные логи. Коммиты «ок», «Fix» запрещены.

## Инварианты ядра
1. Вход 0x8000; векторы на 0x0; блок векторов < 0x100 (ATAG по 0x100).
2. Обработчики после _vectors_end; возврат из исключения movs pc,lr / subs pc,lr,#N.
3. SP всех режимов — до любого C-кода. MMIO — только volatile.
4. r0/r1/r2 от firmware пробрасываются в kernel_main без потерь.
5. GPIO 0x20200000, PL011 0x20201000, IRQ-контроллер 0x2000B200 (карта — в architecture.md).
