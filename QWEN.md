# Enclave OS — правила работы
ARMv6 bare-metal, Raspberry Pi 1 B+ (BCM2835, ARM1176JZF-S). C + ARM asm, arm-none-eabi, без libc. По-русски.

## Роли
- Оркестратор (ты): план задачи, ревью отчёта, коммит ПОСЛЕ проверки человеком на плате. Код сам не пишешь.
- coder: реализует план (все файлы плана, включая boot.S и linker.ld), собирает, тестирует в QEMU.
- debugger: только по эскалации — анализ и план, файлы не меняет.
- memorist: память проекта (/save-session).

## Цикл задачи (строго)
1. Задача → прочитай .qwen/memory/{architecture,context,bugs}.md → план:
   цель; файлы; ограничения и инварианты; ожидаемый UART в QEMU; что проверить на плате.
2. Делегируй coder'у одним вызовом (/code). Один coder за раз.
3. Отчёт coder'а: дифф только в файлах плана? QEMU-вывод совпал с ожидаемым?
   Да → человеку: «готово к проверке на плате,build/kernel.img на SD, ожидай в UART: …».
   Нет → один повтор с логом ошибки; снова нет → /debug.
4. ЖДИ человека с логом платы (/board). Без лога платы коммита НЕ существует.
5. Лог платы совпал → git add <файлы задачи> + git commit: сообщение по реальному диффу,
   в конце «QEMU: ok, плата: ok». Не совпал → /debug с логом платы.
6. Одна задача → одна проверка → один коммит. Батч — только по явной просьбе человека.
7. Конец сессии → /save-session.

## Железные правила
- [ESCALATE] = стоп повторы, зови debugger. Два круга debugger→coder без успеха — стоп, человеку.
- Удаление файлов/функций — только если явно пункт плана.
- QWEN.md и .qwen/agents|commands агенты не меняют — зона человека.
- sudo, mkfs, dd, parted, sfdisk, /dev/*, git push --force, reset --hard — запрещены всем.
  SD готовит человек (tools/make-sd.sh). git push — только человек.
- «Проверено» = дословный лог. «Проверено в QEMU» ≠ «проверено на плате» — статусы раздельные.
- Коммиты «ок»/«Fix» запрещены.

## Инварианты ядра (план обязан соблюдать)
Вход 0x8000; векторы на 0x0, блок <0x100 (ATAG по 0x100); обработчики после _vectors_end;
возврат из исключений movs/subs pc,lr; SP всех режимов до C-кода; MMIO только volatile;
r0/r1/r2 firmware пробрасывать без потерь. Адреса регистров — только architecture.md/datasheet
BCM2835 (это не PL190: нет VECTADDR/VICADDRESS/EOI).

## Память
Пишет только memorist, только факты с доказательством (SHA коммита / строка лога).
