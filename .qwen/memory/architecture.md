# Архитектура Enclave OS (ARMv6, BCM2835)

## Железо
- Плата: Raspberry Pi 1 Model B+
- SoC: Broadcom BCM2835
- CPU: ARM1176JZF-S (ARMv6, VBAR отсутствует — векторы обязаны лежать на 0x00)
- RAM: 512 МБ

## Карта памяти
- 0x00000000 ... 0x1FFFFFFF   RAM для ARM
- 0x20000000 ... 0x20FFFFFF   Периферия BCM2835

## Ключевые адреса
- 0x00000000 — векторная таблица (куда копируется блок `[_vectors_start, _vectors_end)`)
- 0x00000100 — ATAG-список от firmware
- 0x00008000 — точка входа ядра (kernel.img)
- 0x20000000 — база периферии (`MMIO_BASE` в uart.c)
- 0x20200000 — GPIO (`GPFSEL1` = +0x200004, `GPPUD` = +0x200094, `GPPUDCLK0` = +0x200098)
- 0x20201000 — UART PL011 (`DR` +0x00, `FR` +0x18, `IBRD` +0x24, `FBRD` +0x28, `LCRH` +0x2C, `CR` +0x30)
- 0x20003000 — System Timer (1 МГц)
- 0x2000B200 — контроллер прерываний (линия PL011 = 57)

## Режимы и стеки
- User — анклав. Стек НЕ инициализирован намеренно: его назначает ядро при входе в анклав
- Supervisor — ядро, 64 КБ
- IRQ / FIQ / Abort / Undefined — по 4 КБ (`.skip 4096` в boot.S)

## Векторы исключений
0x00 Reset, 0x04 Undef, 0x08 SVC, 0x0C PAbt, 0x10 DAbt, 0x14 resvd, 0x18 IRQ, 0x1C FIQ

## Инварианты — нарушать нельзя
1. Размер блока `[_vectors_start, _vectors_end)` обязан быть < 0x100 (сейчас 60 байт): по 0x100 лежат ATAGS.
2. Обработчики исключений — строго после `_vectors_end`, иначе их тоже скопирует на 0x0. Пул литер `.ltorg` от `ldr pc, =…` — в пределах 4 КБ от инструкции.
3. Возврат из исключения — только `subs pc, lr, #N`, не `bx lr`.
4. Ни одной инструкции со стеком до инициализации SP в `_start`.
5. Регистры периферии — только `volatile`, иначе `-O2` съест доступы.
6. Прототипы C — в заголовке: GCC 14 считает implicit declaration ошибкой.
7. Рецепты `makefile` — с таба, не с пробелов.
8. Ядро грузится на 0x8000, low memory 0x0…0x7FFF зарезервирована.

## Правила кода
- Только `volatile uint32_t*` для MMIO. Никакой стандартной библиотеки C.
- Стек растёт вниз. Вывод в UART — строго ASCII.
- Комментарии по-русски, отступы 4 пробела (в `makefile` — табы).
- Проверка: `make && make check`, прогон `make run` (нужен настоящий терминал, не pipe).
