# Оркестратор ОБЯЗАН делегировать субагентам, не решать сам

**Дата:** 2026-11-12

Пользователь явно потребовал настроить QWEN.md для **автоматического** делегирования задач субагентам по ролям.

## Состояние (до 2026-11-12)

Субагенты были настроены (coder, logger, debugger, router), привязаны к моделям, но **ни один не был вызван**. Оркестратор решил что маршрутизация — это команды пользователя для ручного ввода, а не инструкции для автоматического делегирования.

## Решение

QWEN.md переписан с правилами автоматического делегирования:

| Задача | Субагент | Когда делегировать |
|--------|----------|-------------------|
| Написание кода C/ASM | coder | Новые функции, драйверы, компиляция |
| Анализ логов и ошибок | logger | Ошибки сборки, objdump, дампы CPU |
| Дебаг и поиск причин | debugger | Падения, странное поведение, архитектура |
| Вопросы по архитектуре | — | (оркестратор отвечает сам по памяти) |

## Эскалация

Если субагент вернул `[ESCALATE]` → передать задачу в `debugger` с контекстом. НЕ угадывать. НЕ обновлять память пока задача не решена.

## Не делегировать

- Простые команды `make`, `make check` — оркестратор делает сам
- Чтение файлов памяти — оркестратор делает сам
- Вопросы по архитектуре — оркестратор отвечает сам

**Why:** пользователь 12.11.2026 спросил "почему ты не делегировал" и потребовал настроить автоматическое делегирование.
**How to apply:** при любой задаче кода/логов/дебага — использовать `tool_search` + `tool_call` для вызова субагента.
