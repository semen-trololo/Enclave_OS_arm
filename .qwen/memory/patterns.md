# Паттерны ошибок и правила (обновлено 15.11.2026)

## Типы и сборка
- arm-none-eabi: uint32_t = unsigned long. Выходные параметры — uint32_t*, не unsigned int*.
  Неправильно: f(unsigned int *n); правильно: f(uint32_t *n). Проверять ЦЕЛЕВЫМ тулчейном.
- for/if без скобок + следующий оператор на «внутреннем» отступе → -Wmisleading-indentation.
  Правильно: всегда фигурные скобки у циклов с телом-одной-строкой.
- Рецепты makefile — табы; прототипы — в .h (GCC14: implicit declaration = error).
- Деление на ARMv6 → __aeabi_uidivmod → линковать -lgcc.

## MMIO / UART / GPIO
- MMIO без volatile: -O2 съедает доступы. Только *(volatile uint32_t*).
- Запись в UART без ожидания TXFF и без таймаута → потеря байтов/вечный цикл.
  Правильно: while ((FR & TXFF) && timeout) timeout--; if (timeout) DR = c;
- GPPUD/GPPUDCLK для GPIO14/15 на Pi1 не трогать — прошивка уже настроила, цикл виснет.
- init_uart_clock=3000000 + core_freq=250 обязательны: иначе делители 1/40 не дают 115200.
- Невыровненный SP → кадр съезжает, дамп врёт. SP = символ, кратный 8.
- LED: GPIO47 active high (B+), не GPIO16 (B).

## Стенды
- QEMU raspi1ap: ELF → прямой старт, r0=r1=r2=0, ATAG SKIP — норма, не «чинить под QEMU».
- Плата: без device_tree= r2=0 (DT не найден) → SKIP; с device_tree= ожидаем ATAG по 0x100.
- QEMU -serial stdio в pipe буферизуется → -serial file: + cat (make qemu-log).
- Сырой img в QEMU без loader'а грузится на 0x10000, не 0x8000.
- sd/ — транзитный: всегда пересобирать комплект из firmware/+config.txt+build/kernel.img,
  иначе залёжные файлы молча уезжают на карту (случай: config.txt 972 Б, baud 103448).

## Промты coder'у и дисциплина
- Неправильно: «исправь 3 бага» без файлов/строк → coder переписывает файл целиком.
- Правильно: конкретные файлы, старое/новое, лимит ~30%, список НЕ ТРОГАТЬ, точные команды
  сборки/теста, ожидаемый UART дословно, эскалация после 3 неудач.
- Отчёт = git diff --stat + дословный лог. «Работает» без лога — не отчёт.
- Коммит — НЕ шаг coder'а: только оркестратор после /board с логом платы.
- Удаление файлов — только по явному списку плана (грабли: make-sd.sh удалён зря в 767f0bf).
- Сообщение коммита — по реальному диффу + «QEMU: ok, плата: ok»; «все починили» — запрещено.
