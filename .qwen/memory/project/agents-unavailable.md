# Все субагенты недоступны — нет ни одной модели

## Факт (12.11.2026)
Все 5 настроенных субагентов (`coder`, `logger`, `debugger`, `router`, `memorist`) настроены на проксирование через `openai:` API, но ни одна модель не установлена:
- `qwen3-coder-30b-a3b-instruct` (coder)
- `gpt-oss-20b` (logger, memorist)  
- `deepseek-v3.2` (debugger)
- `qwen3.6-35b-a3b` (router)

## Последствия
- Все попытки делегирования возвращают `404 Model not found`
- Никакое сидение не может использовать субагентов для автоматизации
- Оркестратор вынужден решать используя только основную модель

## Решение
1. Установить необходимые модели через сисадминский интерфейс
2. Либо заменить `model:` на существующие локальные модели (например `qwen2:0.5b` как в `qwen3.6-35b-a3b`)
3. Либо убрать поля `model:` для использования регулярных агентов
