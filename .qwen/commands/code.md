Сам код не пиши. Запусти инструмент `agent` c `subagent_type: coder`, передав в `prompt` текст задачи ниже плюс контекст, который уже есть в разговоре: имена файлов, адреса, вывод сборки. Пропуск контекста = угадывание адресов.

Если coder вернул `[ESCALATE]` → запусти `agent` c `subagent_type: debugger`, передав и задачу, и причину эскалации дословно. Память при этом не обновляй.

Если coder вернул `[PATTERN]` или `[DECISION]` → после успешной проверки вызови /remember-pattern или /remember-decision.
